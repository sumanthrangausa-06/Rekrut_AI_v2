# Rekrut AI — Visily Design Gap Analysis

> **Date:** 2026-06-09
> **Source:** Visily design screenshots (41 files in workspace/downloads/)
> **Analyst:** Suga (CEO)

---

## EXECUTIVE SUMMARY

The Visily designs show a **significantly more feature-rich and polished application** than what currently exists. Key gaps span across **homepage, dashboard analytics, profile creation, recruiter-candidate chat, video interviews, and onboarding flows**. Many features in the Visily designs are **not yet implemented** in the current app.

---

## 🔴 CRITICAL GAPS (Ship-Blocking)

### 1. Homepage Missing Core Elements
**Visily shows:**
- **Hero search bar** — "Search jobs" input with search button
- **Trust bar** — "Trusted by" company logos section
- **Blog section** — 4 blog cards with images, tags, authors, dates
- **Newsletter subscription** — Email input + subscribe button in footer
- **Comprehensive footer** — 5 columns (Product, Resources, Community, Company, Newsletter)

**Current app status:** ❌ None of these exist

### 2. Dashboard Analytics Completely Missing
**Visily shows:**
- **KPI metric cards** — 3 cards with values + trend arrows (+65%, -5%)
- **Line charts** — Multi-series line charts over 12 months
- **Bar charts** — Stacked/compositional bar charts
- **Donut charts** — Proportional breakdowns
- **World map** — Geographic distribution of activity
- **Download reports** — Export to PDF/CSV button

**Current app status:** ❌ No charts, no analytics visualization, no download

### 3. Recruiter-Candidate Chat Missing Advanced Features
**Visily shows:**
- **Audio/video call buttons** — Phone + camera icons in chat header
- **File sharing** — PDF attachments (JD, CVs) with download
- **Contact profile panel** — Right sidebar showing shared files, tags, bio
- **Status indicators** — Online/away/busy dots
- **Message timestamps** — Time + date grouping ("Today", "Mon", "Nov 4")
- **Compose new message** — Pencil icon to start new conversation
- **Conversation search** — Search through messages

**Current app status:** ⚠️ Basic chat exists but missing calls, file sharing, profile panel, status indicators

### 4. AI Interview Video Conferencing Missing
**Visily shows:**
- **Full video conferencing UI** — Multi-participant video grid
- **Chat sidebar during interview** — Threaded messages alongside video
- **Screen sharing** — Dedicated share button
- **Meeting controls** — Mute, camera, reactions, effects, settings
- **Participant management** — Add members, name tags, mic indicators
- **End call button** — Red phone button

**Current app status:** ❌ No video conferencing interface exists

## 🟡 HIGH GAPS (Major Feature Gaps)

### 5. Profile Creation Missing Rich Sections
**Visily shows:**
- **Collapsible sections** — General Info, About, Working Experience, Skills, Education (each with chevron toggle)
- **Progress indicators** — "100% completed", "1 company", "5 skills"
- **Skills as removable tags** — Chips with X to remove
- **Working experience** — Company dropdown, employment type, title, date pickers, "currently working" checkbox
- **Add more** — "+ Add job" button for multiple entries
- **Professional title dropdown** — Not just text input

**Current app status:** ⚠️ Basic profile exists but missing collapsible sections, progress indicators, date pickers, multi-entry experience

### 6. Candidate Listing Missing Recruiter Features
**Visily shows:**
- **"Open for work" badges** — Green/blue pill indicator on candidate cards
- **Advanced filters** — Location, Experience Level, Industry, Company Type dropdowns
- **Pagination** — Page numbers with prev/next arrows
- **Connect vs Sent message** — Two button states (primary for connect, gray for already sent)
- **Promotional sidebar** — CTA section with illustration and "Get started" button
- **Candidate cards** — Avatar, name, location, role, skill tags, action buttons

**Current app status:** ⚠️ Basic candidate listing exists but missing badges, advanced filters, pagination states, connect button states

### 7. Sign-Up/Onboarding Missing Steps
**Visily shows:**
- **Role selector** — "JobSeeker/Employer" dropdown at registration
- **LinkedIn OAuth** — "Sign up with LinkedIn" button
- **Theme toggle** — Light/dark mode switch
- **Progress indicator** — "First things first..." suggests multi-step
- **Password show/hide** — Eye icon toggle

**Current app status:** ⚠️ Basic registration exists but missing role selector, LinkedIn OAuth, theme toggle, multi-step flow

### 8. Company Profile Page Missing
**Visily shows:**
- **Company profile page** — Logo, description, open positions, team members, culture info
- **Career page** — Dedicated page for company careers

**Current app status:** ❌ No company profile page exists

### 9. Skill Upgrade/Certification Missing
**Visily shows:**
- **Skill upgrade page** — Free vs paid tier comparison
- **Certification badges** — Verified skill credentials
- **Pricing tiers** — Free basic vs paid premium

**Current app status:** ❌ No skill upgrade/certification page exists

## 🟢 MEDIUM GAPS (Polish & Enhancement)

### 10. Job Listing Missing Filters

- **Sort options** — Relevance, date, salary
- **Job cards** — Company logo, title, location, salary, tags, bookmark button

**Current app status:** ⚠️ Basic job listing exists but could use enhanced filters

### 11. Navigation Missing Dropdowns
**Visily shows:**
- **JobSeeker dropdown** — Sub-navigation for candidate features
- **Employer dropdown** — Sub-navigation for recruiter features
- **Mega menu** — Rich dropdowns with icons and descriptions

**Current app status:** ❌ No dropdown menus in navigation

### 12. Verification/KYC Flow Missing
**Visily shows:**

- **Business verification** — Company/business account verification
