**Blockers — both real, both fixed:**
- **B-1 identity binding poisoning.** `verifyIdentity` auto-bound the first identity shown; an interviewer publishing before the candidate joined would be bound and captured under the candidate's DEK/consent. Fix: the worker derives the expected identity at Gate 2 from the session's `candidate_id` (`candidate-<userId>` convention, or the metadata-resolved participant whose userId must equal `candidate_id` — a disagreement stays dormant with `CAPTURE_ROLE_IDENTITY_MISMATCH`); binding is explicit and unconditional; `verifyIdentity` is now pure and fail-closed (never binds); `TrackPublished` subscribes ONLY the bound identity, treats any other candidate-prefixed identity as `role_flip`, and ignores interviewer identities entirely. Proven by pack S10 + jest.
- **B-2 teardown never unsubscribed.** `stopCapture` now unsubscribes every capture publication (`setSubscribed(false)`, allSettled) and cancels every stream reader BEFORE finalize — the kill stops collection, not just persistence, inside the same ≤2 s bound. Asserted in pack S4 and jest T5.

**Majors fixed:** M-1 (remainder) reconciler retires each intent in a per-row transaction under the candidate lock with a still-pending re-check; M-2/A-10 test-decrypt guard is now an identity ALLOWLIST (staging/development/test) — `unknown` previously failed open — plus a 10 MB object cap; M-4 measurement persist reordered (lock → job → tombstone check → gate → encrypt, so discarded writes mint nothing) and erasure of a DEK-less candidate now leaves a destroyed **tombstone** row so no late write can resurrect key material; M-6/A-7 the session's truncation state is passed into the speech computation and surfaces as `INPUT_TRUNCATED` degraded flags. M-3 was DB M1 (already fixed); M-5 dispositioned below.

**Privacy red-line completions:** RL-03 — `TrackSubscribed` re-reads the flag at handler entry and the capture watchdog now stops at the FIRST failed recheck (§6.3; persist-time re-checks independently block writes, so a transient failure costs the capture, never the data); A-5 — the withdrawal sweeper consults the hold seam per session, and the test purge is per-row hold-checked across chunks, measurements AND outcome rows (§5.5 completed); A-6 — the reconciler no longer runs inside a dry-run retention pass; A-11 — activation cohort resolution ignores `test_harness`-sourced snapshots (executed case in the gate harness); RL-11 — log lines map `flag_state` to the `on|off` enum, counts are sanitised to numeric values by construction, chunk indices no longer appear on routine lines, and the pre-existing role-fallback log no longer prints a candidate ID. RL-10 note: the concurrency-cap outcome row is KEPT — §8.5's own stop_reason enum includes `concurrency_cap`, and the row is counts-only with no media ever consumed.

**§7.5 contract completed (A-8/A-9 + schema):** `observerSpeech` now emits the design's measurement shape verbatim — `uncertainty` is a data-derived number on every non-missing entry (frame quantum, standard errors, IQR/2, confidence-scaled) and `null` iff missing; `uncertainty_kind` uses the §7.5 enumeration (`f0_confident_frame_ratio`, `asr_mean_confidence`, `capture_gap_ratio`, `segment_count`); `method_version` is the integer 1; a degraded post-pass marks entries `degraded` with `GAP_IN_CAPTURE` (>5% capture gap), `INPUT_TRUNCATED`, or `ASR_CONFIDENCE_UNAVAILABLE` (M8/M9 when ASR reports no confidence — the real whisper path today, so those values can no longer masquerade as clean). A-9 honesty bugs fixed: zero pauses now yield `mean_sec`/`max_sec` = null (was a fabricated 0), and a zero-length turn yields `INSUFFICIENT_SPEECH` (was a fabricated 0 wpm).

**Minors:** AAD components must be integers (injective binding); the store's intent-less `putEncryptedChunk` wrapper was REMOVED — `putEncryptedChunkAtKey` is the only write entry point, so an unregistered object is impossible at the API level; the erasure jest suite's call shape was corrected to the function's real signature. **Dispositioned without code change, with reasons:** SEC M-5 — `uploadFile`'s traversal guard stays as built; a global key allow-list there risks other callers' legitimate key shapes, and for THIS unit the binding validation is the store's own strict bare-key pattern enforced before any PUT (a global allow-list is a separate hardening story if wanted); SEC minor 5 (zero chunk sources at flush) — the chunk and measurement accumulations share single-copy buffers by design (§3.7 memory bound); they are zeroed at finalize and on every discard path, and zeroing at flush would corrupt the measurement audio.
